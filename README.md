# Testimonial-Box
A simple and clean **Testimonial Box UI** created using **HTML & CSS**.

## Features

- Clean and simple testimonial design
- Styled testimonial card
- Quote icon and customer name
- CSS borders, colors and spacing
- Simple and beginner-friendly UI

## Technologies Used

- HTML5
- CSS3
